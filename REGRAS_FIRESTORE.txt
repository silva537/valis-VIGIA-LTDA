VALIS VIGIA — REGRAS DE SEGURANÇA (8.2.1)

COMO PUBLICAR AS REGRAS
1. Firebase Console → Firestore → Rules → colar firestore.rules → Publish
2. Firebase Console → Storage → Rules → colar storage.rules → Publish
3. Authentication ativo (Anonymous) — o app usa signInAnonymously.

O QUE MUDOU
- Negar tudo por padrão
- Só documentos da lista valis/* podem ser lidos/escritos
- Delete de documentos raiz bloqueado no cliente
- Limite de tamanho de escrita
- fcm_tokens na lista permitida
- Storage fechado + pastas por uid

LIMITES
Enquanto houver um único db_v42 + Auth anônimo, usuário autenticado no app
pode ler/escrever esse documento. Proteção fina por cargo no servidor exige
Custom Claims ou Cloud Functions.

NUNCA use: allow read, write: if true
NUNCA coloque service account / chave privada no HTML
